# 관리자 화면 비밀값 설정 방법 (한 번만 하면 돼요)

관리자 화면이 동작하려면 **Vercel에 비밀값 2개**를 넣어야 해요.
비밀값은 코드나 GitHub에는 저장되지 않고 **Vercel 설정 안에만** 보관돼요. 이 작업은 직접 해 주셔야 해요(비밀번호·열쇠는 Claude가 대신 입력하지 않아요).

| 이름 | 무엇인가요 |
|---|---|
| `ADMIN_PASSWORD` | 관리자 화면 로그인 비밀번호 (직접 정하기) |
| `GITHUB_TOKEN` | 관리자 화면이 GitHub에 저장할 때 쓰는 열쇠(토큰) |

---

## 1. GitHub 열쇠(토큰) 만들기
1. https://github.com/settings/personal-access-tokens/new 접속 (GitHub 로그인)
2. **Token name**: `portfolio-admin`
3. **Expiration**: 가장 긴 기간 선택(보통 1년). 만료일은 달력에 적어 두세요.
4. **Repository access**: `Only select repositories` → `kgh915/portfolio` 하나만 선택
5. **Permissions → Repository permissions → Contents**: `Read and write`
6. 맨 아래 **Generate token** → 나온 `github_pat_...` 글자를 복사
   - 이 화면을 닫으면 다시 볼 수 없어요. 바로 2번 단계로 넘어가세요.

## 2. Vercel에 비밀값 넣기
1. https://vercel.com 로그인 → 프로젝트 **portfolio** 클릭
2. 위쪽 **Settings** → 왼쪽 **Environment Variables**
3. 첫 번째 값 추가
   - Key: `ADMIN_PASSWORD`
   - Value: 관리자 비밀번호(12자 이상, 다른 곳에서 안 쓰는 것 추천)
   - Environments: **Production**, **Preview** 둘 다 체크 → **Save**
4. 두 번째 값 추가
   - Key: `GITHUB_TOKEN`
   - Value: 1번에서 복사한 `github_pat_...`
   - Environments: **Production**, **Preview** 둘 다 체크 → **Save**
5. 저장한 뒤 Claude에게 **"비밀값 넣었어"**라고 알려주세요. 새 값이 적용되도록 다시 배포하고 확인할게요.

## 열쇠가 만료됐을 때 (저장이 안 될 때)
- 관리자 화면에서 저장하면 "저장하지 못했어요. GitHub 401…" 같은 메시지가 나와요.
- 1번처럼 새 열쇠를 만들고, Vercel → Settings → Environment Variables에서 `GITHUB_TOKEN` 값을 **Edit**로 바꾼 뒤 Deployments 화면에서 마지막 배포를 **Redeploy** 하면 돼요.

## 비밀번호를 바꾸고 싶을 때
- Vercel → Settings → Environment Variables → `ADMIN_PASSWORD` → **Edit** → 새 비밀번호 → Save → 마지막 배포 **Redeploy**

---

## 3. 통계 연결하기 (4단계, 한 번만)

### 3-1. 숫자 저장소(Upstash) 연결 — Vercel 안에서 바로
1. https://vercel.com → 프로젝트 **portfolio** → 위쪽 **Storage** 탭
2. **Create Database**(또는 Browse Marketplace) → **Upstash** → **Upstash for Redis** 선택 → 안내에 따라 무료(Free) 플랜으로 만들기
   - 지역(Region)은 **Tokyo**나 **Seoul**처럼 한국과 가까운 곳 추천
3. 만든 뒤 **Connect Project** → `portfolio` 선택, 환경은 **Production·Preview 모두** 체크 → Connect
   - 연결하면 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 같은 값이 Environment Variables에 **자동으로** 들어가요(직접 입력할 필요 없음).

### 3-2. 메일 보내기(Resend)
1. https://resend.com 가입 — **통계를 받을 이메일 주소로** 가입 (무료 플랜은 가입한 주소로만 보낼 수 있어요)
2. 왼쪽 **API Keys** → **Create API Key** → 이름 `portfolio-stats`, 권한 **Sending access** → 만들기 → `re_...` 글자 복사 (다시 볼 수 없어요)
3. Vercel → Settings → Environment Variables에 아래 3개 추가 (Production·Preview 모두 체크)

| Key | Value |
|---|---|
| `RESEND_API_KEY` | 방금 복사한 `re_...` |
| `STATS_EMAIL` | Resend에 가입한 이메일 주소 |
| `CRON_SECRET` | 아무 글자 20자 이상(예: 영문·숫자 섞어서). 매주 자동 메일이 진짜 Vercel에서 온 요청인지 확인하는 용도 |

4. 다 넣었으면 Claude에게 **"통계 설정 넣었어"**라고 알려 주세요. 다시 배포해서 확인할게요.

- 매주 자동 메일은 **실제 사이트(main)에 합친 뒤부터** 월요일 오전 8~9시 사이에 와요. 그 전에는 관리자 화면 '통계' → **시험 메일 보내기**로 확인할 수 있어요.
- 메일이 안 보이면 네이버 메일 **스팸함**도 확인해 주세요(보내는 사람: onboarding@resend.dev).
