## 3. Vercel 무료(Hobby) 플랜 확인 결과
| 기능 | 무료 플랜 | 대안 |
|---|---|---|
| 방문자 통계(Web Analytics) | **가능** — 월 50,000건(페이지 조회), 데이터 보관 1개월, 한도 넘으면 수집 일시 중지 | 매월 CSV 내려받기(패널별 최대 250줄) |
| 작업별 클릭 기록(사용자 정의 이벤트) | **불가** — 유료(Pro)에서만 | 아주 가벼운 자체 클릭 카운터(무료 저장소) |
| 통계 데이터 API로 가져오기 | 무료 플랜 지원 여부 **공식 확인 안 됨** | 자체 카운터 값으로 보고서 |
| 예약 실행(매주 메일) | **가능** — Cron Job은 하루 1번까지(주 1회는 문제없음), 실행 시각은 지정한 시의 1시간 안에서 랜덤 | — |
| 이메일 발송 | Vercel 자체 기능 없음 → 외부 무료 서비스 Resend(하루 100통·월 3,000통 무료) | 도메인 없이 보내면 **본인 계정 이메일로만** 발송 가능(통계 받기엔 충분) |
| 사용 조건 | 개인·비상업용만 가능 → 개인 포트폴리오는 해당 | — |

## 4. 기술적으로 미리 고칠 점
- `build.py`가 맥 전용 명령(`sips`)을 써서, 서버(Vercel)에서 사이트를 다시 만들 때 실패함 → 맥과 서버 모두에서 되는 방식으로 교체
- 이미지 캐시 버스팅이 파일 수정 시각 기준 → 서버에서는 매번 바뀌므로 파일 내용 기준으로 교체
- 관리자 저장 → GitHub 저장 → Vercel이 `build.py`를 실행해 사이트를 다시 만드는 흐름으로 구성

## 5. 의뢰인이 정할 것
1. 작업별 클릭 기록: 자체 카운터(무료, 추천) / 빼기 / Vercel Pro($20/월)
2. 매주 통계 메일: 자체 카운터 기반 메일(무료, 추천) / 매월 CSV 직접 내려받기만
3. 통계를 받을 이메일 주소
